\begin{abstract}
图与超图检索器通常缺少逐步证据标签，因而从主题实体到答案实体选择一条最短路径作为正监督，并把未被选中的候选采样为负例。然而，未被选中并不等于安全负例：候选可能仍位于另一条完整最短答案路径上。本文将同时具有负标签与完整最短答案路径成员资格的实际采样候选定义为路径一致负例。对 WikiTopics 的 \DatasetCount{} 个领域审计表明，这类候选占全部采样负例的 \ConflictRate\%，并影响 \AffectedQueryRate\% 的训练问题。我们提出不改标签、不增参数且不改变推理的最小修正：仅屏蔽这些候选的负损失。验证集领域等权分析选择全局 $\lambda=\GlobalValidationLambda$；随后明确标记的事后简化分析显示，相对原基线，路径一致屏蔽将 APC-MRR 和 Reach@10 分别改变 \OursBaselineMRRDelta{} 与 \OursBaselineReachTenDelta{} 个百分点；相对等量随机屏蔽，对应差值为 \OursRandomMRRDelta{} 与 \OursRandomReachTenDelta{} 个百分点。该随机对照表明，关键是屏蔽哪些负例，而非仅减少多少负监督。本文结论限于结构性质和 Retriever-only 设置，不把路径一致性解释为语义真值，也不声称复现端到端生成质量。
\end{abstract}

\section{引言}

检索增强生成将外部证据检索与生成模型结合，使知识访问不再完全依赖参数记忆\cite{lewis2020rag}。当证据以图或超图组织时，检索器还需从庞大的结构空间中找出连接问题实体与答案实体的紧凑子图\cite{sun2019pullnet,zhang2022subgraph,he2024gretriever,lien2026hyperrag}。然而，多跳问答基准通常只提供最终答案，缺少逐步检索标签。常见做法是从主题实体到答案实体选择一条最短路径作为正监督，再从路径引导的候选子图中采样负例。

这一做法隐含了``未被选中即为负例''。当多个完整最短答案路径共享相同长度时，某条未被选路径上的转移仍可能被负采样器选中。于是同一个候选一方面属于完整最短答案路径，另一方面又被作为确定负例压低。我们称其为\emph{路径一致负例（Path-consistent Negative）}。该名称只描述结构成员资格：它不是语义正例、人工确认的错误负例，也不改变 benchmark 标签。

这不是仅存在于理论候选空间的边缘情形。对正式训练输入的审计发现，\SampledNegativeCount{} 个实际采样负例中有 \PathConsistentNegativeCount{} 个满足完整路径条件；按领域等权，\AffectedQueryRate\% 的问题至少在一个训练种子中受到影响。由此产生一个直接问题：若其他候选、特征、模型和推理保持不变，只去除这部分结构冲突的负监督，能否改善检索？

本文采用最小干预。最终方法\emph{路径一致负例屏蔽}只把这类候选的损失权重置零。为排除``少训练了一些负例''这一解释，我们构造逐问题等量随机屏蔽：它从同一批采样负例中均匀选择恰好 $|D_q|$ 个候选，但不查看路径身份。正式实验隔离 HyperRetriever 的 GTE 文本表示、DDE 结构编码和两层 MLP，不调用生成式模型、人工标注或 LLM Judge。

本文贡献不超过三点：

\begin{itemize}
  \item 形式化单路径弱监督中的路径一致负例，并量化其真实进入 Retriever 损失的规模；
  \item 提出不增参数、不改标签和推理的路径一致负例屏蔽，将修正严格限制在已采样的结构冲突候选；
  \item 通过逐问题等量随机屏蔽对照，区分路径定位信息与单纯减少负监督，并用固定候选池上限诊断候选生成与排序误差。
\end{itemize}

\section{相关工作}

\paragraph{图结构检索。}
稠密检索与 RAG 奠定了可学习检索器访问外部证据的基础\cite{karpukhin2020dpr,lewis2020rag}。PullNet 迭代扩展问题相关子图\cite{sun2019pullnet}，可微子图检索研究答案覆盖与噪声之间的权衡\cite{zhang2022subgraph}，G-Retriever 和 SubgraphRAG 分别从文本属性图和知识图谱 RAG 角度研究结构证据选择\cite{he2024gretriever,li2025subgraphrag}。HyperRAG 以超图保留高元事实，并从答案路径派生 HyperRetriever 标签\cite{lien2026hyperrag}。本文不替换检索骨干，而是审查路径派生监督本身。

\paragraph{不完整监督与负例。}
正例---未标注学习指出，未观察到正标签不自动构成可靠负标签\cite{elkan2008pu,kiryo2017nnpu}；去偏对比学习也揭示了假负例对表示目标的影响\cite{chuang2020debiased}。与估计语义真值不同，我们只使用可复算的完整最短路径条件定位监督冲突，不把这些候选重新标为正例。

\paragraph{路径派生监督。}
已有工作利用答案可达路径构造检索监督或学习信息量更高的路径\cite{zhang2022subgraph,cattaneo2025groundtruth,gao2026pathise}。我们的关注点更窄：单路径监督会把另一条完整最短答案路径上的实际采样转移当作负例。方法既不枚举所有路径，也不扩大正例集合，而是只屏蔽进入损失的冲突负项。

\section{路径一致负例屏蔽}

\subsection{完整路径判据}

对问题 $q$，令 $S_q$ 和 $A_q$ 分别为主题实体集合与正确答案实体集合。确定性超图以 incidence graph $G_I$ 表示；候选转移 $t=(v,f,u)$ 表示从实体 $v$ 经事实节点 $f$ 到实体 $u$，消耗两条 incidence edge。令 $d_I(x,y)$ 为无权最短距离。

\begin{definition}[路径一致负例]
设 $N_q$ 为原训练流程实际采样的负例集合。若 $t=(v,f,u)\in N_q$，且存在 $(s,a)\in S_q\times A_q$ 满足
\begin{equation}
  d_I(s,v)+2+d_I(u,a)=d_I(s,a),
  \label{eq:path-consistency}
\end{equation}
则称 $t$ 为路径一致负例，并记所有此类候选构成 $D_q\subseteq N_q$。
\end{definition}

式~\eqref{eq:path-consistency} 检查完整主题---答案最短路径，而非局部朝答案靠近。实现先计算有界最短路径 DAG，再扫描已经采样的负例；它不枚举组合候选空间。

\subsection{训练目标与三个策略}

对候选 $i$ 的标签 $y_i$、logit $z_i$，令
\begin{equation}
  w_i(\lambda)=
  \begin{cases}
    \lambda, & i\in D_q,\\
    1, & \text{其他候选},
  \end{cases}
\end{equation}
并以权重和归一化逐样本 BCE：
\begin{equation}
  \mathcal L_B(\lambda)=
  \frac{\sum_{i\in B}w_i(\lambda)\operatorname{BCEWithLogits}(z_i,y_i)}
  {\sum_{i\in B}w_i(\lambda)}.
  \label{eq:loss}
\end{equation}
$\lambda=1$ 与原 mean BCE 的数值和梯度严格等价；$\lambda=0$ 与删除 $D_q$ 后在剩余样本上求均值严格等价。若整个 batch 均被屏蔽，则跳过该步反向传播和 Adam 更新。

主文只比较三个策略。\textbf{策略1}保留所有原负监督。\textbf{策略2}对每个问题从全部已采样负例中均匀无放回屏蔽恰好 $|D_q|$ 个候选，不读取路径身份。\textbf{策略3}只屏蔽 $D_q$。三者共享候选池、GTE、DDE、MLP、优化器、种子、早停和推理候选，因此策略2专门检验收益来自``屏蔽哪些负例''还是``屏蔽多少负例''。

\section{实验设计}

\subsection{数据、图与受控检索器}

我们使用 WikiTopics 的 \DatasetCount{} 个领域。主题实体直接取自结构化查询 $(e,(r_1,r_2,r_3))$ 中的 $e$；自然语言问题与结构化查询只按发布顺序和主题标签进行单调对齐，不读取答案标签。答案仅用于构造训练路径、判断式~\eqref{eq:path-consistency} 和评价。经 answer-free 对齐与图内实体条件过滤后，共有 \AlignedQueryCount{} 条对齐查询和 \EligibleQueryCount{} 条可评价查询。

我们把训练图与测试推理上下文组成同一传导式检索语料，再按头实体把高元事实确定性重建为事实节点。测试问题和答案标签不参与建图；测试答案不参与候选生成、GTE 相似度、DDE、MLP 特征或分数。所有策略共享同一图。实体身份始终使用 Wikidata QID，英文标签只作为文本编码输入。

检索器复用 HyperRetriever 的本地 GTE-large-en-v1.5 表示、\DDEDimension{} 维 DDE 和两层 MLP。训练使用固定的 batch size \TrainingBatchSize、最多 \MaximumEpochs{} 个 epoch，并以 patience \EarlyStoppingPatience{} 早停。推理从主题实体出发至多扩展 \MaximumLogicalHops{} 跳，只依据冻结 GTE 相似度构造宽度为 \SelectedBeamWidth{} 的候选池；候选生成不读取答案或训练后 MLP 分数。

\subsection{指标、统计与研究问题}

对问题 $q$，按 Retriever 分数降序排列候选转移，并记 $\operatorname{rank}(t)$ 为转移 $t$ 的排名。定义 Answer-Path Completion rank 为
\begin{equation}
  r_q=\min_{P\in\mathcal P_q}\max_{t\in P}\operatorname{rank}(t),
\end{equation}
其中 $\mathcal P_q$ 是候选池中的完整主题---正确答案有向路径集合。若 $\mathcal P_q$ 为空，则 $RR_q=0$；否则 $RR_q=1/r_q$。\emph{Answer-Path Completion MRR（APC-MRR）} 为 $RR_q$ 的问题平均。该指标不是实体排序 MRR；它衡量完整答案路径多早在排序前缀中形成。实现通过依次加入 top-$k$ 转移寻找首次可达的 $k$，toy test 验证其与上述 min--max 定义等价。次指标为 Reach@10；Reach@5 仅见附录。

每种方法使用 \TrainingSeedCount{} 个共享种子。我们先在同一问题上等权平均种子，再做 \BootstrapResamples{} 次 query-level paired bootstrap；跨领域采用领域等权宏平均。本文只回答两个研究问题：\textbf{RQ1}，路径一致负例是否真实进入损失、规模多大？\textbf{RQ2}，针对性屏蔽是否优于原基线与等量随机屏蔽？Candidate Oracle 仅作为 RQ2 的候选池诊断。

\subsection{从软抑制到固定屏蔽}

冻结网格的领域级选择见附录。另行进行的验证集领域等权分析在不读取 test 的前提下选择全局 $\lambda=\GlobalValidationLambda$。由于早期正式 test 已在该简化问题提出前访问，固定 $\lambda=0$ 的 test 比较被明确标记为\textbf{事后简化分析}，不伪装成原始确认性协议。它同时回答一个方法设计问题：固定屏蔽是否足以替代按领域校准的软抑制。

固定屏蔽与原领域校准策略的 APC-MRR 差值为 \FixedTunedMRRDelta{} 个百分点，\mbox{95\% CI} [\FixedTunedMRRCILow, \FixedTunedMRRCIHigh]；Reach@10 差值为 \FixedTunedReachTenDelta{} 个百分点，\mbox{95\% CI} [\FixedTunedReachTenCILow, \FixedTunedReachTenCIHigh]。两个区间均低于零，因此数据不支持二者统计等价；但绝对差异很小，而固定屏蔽仍保留了相对基线的大部分收益。结合验证集的全局最优为零，最终方法采用无领域超参数的路径一致负例屏蔽；完整校准网格保留在附录作为性能上界分析，而不是主方法。

\subsection{Candidate Oracle 诊断}

在完全固定的 beam=\SelectedBeamWidth{} 候选池中，若存在至少一条完整主题---答案路径，则 Candidate Oracle Reach 为一。领域等权宏平均为 \CandidateOracleMacro\%，总体涉及 \CandidateOracleQueryCount{} 个 test 查询。这个上限不训练新模型，也不改变 beam；它把``候选池中没有答案路径''与``候选已存在但排序靠后''分开。表~\ref{tab:oracle} 的逐领域结果表明，当前绝对指标同时受候选生成上限约束，因此本文不把较小的绝对 APC-MRR 误解为纯排序失败。

\section{局限与结论}

本文有四项边界。第一，路径一致性是结构性质而非语义真值；屏蔽避免确定负惩罚，但不证明候选足以回答自然语言问题。第二，我们隔离 Retriever 训练，不评价端到端生成答案。第三，Candidate Oracle 显示固定候选池存在明显上限；扩大 beam 会改变研究问题，本文没有用 test 搜索更宽候选。第四，证据来自 WikiTopics 的多个领域而非独立第二数据集；此外，固定屏蔽 test 比较是透明披露的事后简化分析，后续独立 benchmark 才能提供新的确认性检验。

在这些限制内，结果支持一条紧凑结论：单路径弱监督会把一部分完整最短答案路径成员实际送入负损失；只屏蔽这些结构冲突项优于保留原负监督和等量随机屏蔽。收益来自屏蔽对象的路径位置，而非模型复杂度或简单减少训练信号。
