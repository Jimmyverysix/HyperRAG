# 配图论证与导出约定

沿用项目 Python/matplotlib 后端。图宽约 183 mm，白底、固定低饱和配色，正文文字可编辑；导出 PDF、SVG、300 dpi PNG 预览和 PGF。PGF 内嵌新稿以便单文件编译，不依赖额外图片目录。没有照片、图像增强或合成实验数据。

图1为 schematic-led composite：核心结论是“实际被采样的另一条完整最短答案路径转移，会与所选正路径形成结构监督冲突”。主面板两条两跳链，辅面板三跳绕远反例与四策略操作；示意不是数据案例，图注明确这一点。只连接有效边，不能将局部变近画成 PCN。

图2为 quantitative grid：主面板展示 PCN Mask 与三个控制的配对 APC-MRR 差值及95% CI；辅面板显示四组真实训练 PCN 比例。计数为五种子累计，差值为先按题平均五种子的结果；WikiTopics 等领域。未完整的策略不画估计点，缺失标记为 pending。Source data 保存实际值与 CI，全部来自聚合 JSON，没有模型外推。多重比较未校正，不绘制星号。

图3为 quantitative grid：描述训练 topic 的 PCN 密度和答案跳数与 held-out 改善的关系，点旁标题数。KQAPro 高密度桶很小，必须显示；没有逐桶 CI，不用误差条冒充不存在的推断。训练 topic 未匹配题被排除于密度面板，不排除于主实验。Source data 包含所有桶、分母和边界。

最终 QA 的具体目标是检查文本重叠、误差条截断、分母不明与无法编辑文字；出现这些失败时调整图布局或标签。使用 Python 渲染并查看 PNG，抽取 PDF 文本确认向量文字可选。已经核对的统计不为图再重复检验。
